# Tech Challenge - Infraestrutura Kubernetes (Terraform)

**Repositório 2 do projeto**: Infrastructure as Code (Terraform) da camada
Kubernetes na AWS — **VPC, EKS, ALB Controller, IAM/OIDC e ECR**. Todo o ciclo de
vida (criar, atualizar e destruir) é versionado aqui e executado por
**GitHub Actions**, com deploy automático das branches de **homologação** e
**produção**.
